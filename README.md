# GitHub 工作流练习

这是一个个人 GitHub 操作练习仓库，用来熟悉 Issue、工作分支、Pull Request 和合并，并观察这些操作对应的 GitHub 成就。

## 从这里开始

- [Issue 与 Pull Request 操作清单](workflow-checklist.md)
- [已经完成的合并请求](https://github.com/Irixil/github-workflow-practice/pulls?q=is%3Apr+is%3Amerged)
- [已经关闭的 Issue](https://github.com/Irixil/github-workflow-practice/issues?q=is%3Aissue+is%3Aclosed)

## 练习步骤

1. 用 Issue 描述待解决的问题，并列出完成条件。
2. 创建工作分支，提交一份有实际内容的文档改动。
3. 发起 Pull Request，写明改动目的和检查结果。
4. 确认改动范围、内容和适用检查，再合并到默认分支。
5. 核对 Issue 的完成条件，关闭 Issue 并删除已完成的工作分支。
